# LTV · DSR 계산기

LTV · DSR 대출 한도 계산 및 상환계획표 도구

## 사용법

`index.html` 파일을 브라우저(Chrome, Edge, Safari)로 열면 바로 실행됩니다.
인터넷 연결 불필요. 설치 불필요.

## 주요 기능

- 매매계약일 / 입주자 모집공고일 입력으로 대책 자동 소급 적용
- 시·도 + 시군구 선택으로 규제지역 여부 자동 판별
- 스트레스DSR 1·2·3단계 + 10·15 대책 자동 반영
- 금리 유형별 (변동/혼합형/주기형/순수고정) 가산율 차등 계산
- 특례 조건: 생애최초, 신혼부부, 청약당첨 소급, 정책모기지
- 주택담보대출 + 신용대출 지원

## 정책 기준

| 대책 | 시행일 | 주요 내용 |
|------|--------|---------|
| 스트레스DSR 1단계 | 2024.2.26 | 은행권 주담대 0.38% |
| 스트레스DSR 2단계 | 2024.9.1 | 수도권 규제 1.2%, 그외 0.75% |
| 6·27 대책 | 2025.6.28 | 수도권 한도 6억, 다주택 불가 |
| 스트레스DSR 3단계 | 2025.7.1 | 수도권 1.5%, 지방 0.75% |
| 10·15 대책 | 2025.10.16 | 규제지역 LTV 40%, 스트레스 3.0% |
